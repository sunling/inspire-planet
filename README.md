# 启发星球 · Inspire Planet

启发星球是一个持续分享真实生活、问题、尝试和变化的共同学习空间。

这个仓库保存会议转写、公众号文章、分享纪要和金句，并支持从本地回放制作原声短视频。每位分享者保有自己的表达与署名；内容公开与发布均以参与者授权为前提。

## 日常工作

| 步骤 | 做什么 | 操作说明 |
| --- | --- | --- |
| 1. 归档转写 | 每周定时下载；必要时手动补录，提交前校验内容和写入范围 | [会议转写与归档](docs/meeting-content.md) |
| 2. 按需整理内容 | 生成公众号文章、网站纪要或金句，不要求每期全部制作 | [内容制作流程](docs/content-workflow.md) |
| 3. 制作短视频并发布 | 手动下载回放 → 推荐选段 → 确认后初剪、字幕和两平台文案 → 审片后发布 | [原声短视频 skill](.agents/skills/inspireplanet-clips/SKILL.md) |

小红书和视频号统一走原声短视频流程，独立封面按需制作。历史图文稿保留供查阅；图文 skills 已退役。旧图卡工具和手动出图入口暂作历史兼容保留，不属于日常维护流程。

## 浏览与使用内容

- [按期浏览会议资料](events/README.md)：查看各期转写、文章、纪要与金句。
- [当前运营信息](current.md)：查看已确认的官网、社群入口和活动信息。
- [AI skills](.agents/skills/)：文章、纪要、金句与原声短视频。使用前请阅读 [AGENTS.md](AGENTS.md)。

## 仓库里有什么

```text
events/             每期原始转写、文章、纪要与金句 JSON；历史图文稿保留
replays/            本地回放、剪辑单、字幕、文案和成片，被 Git 忽略
docs/               转写归档与内容流程说明
.agents/skills/      内容 skills 及短视频本地工具
.github/workflows/   转写下载与内容校验
scripts/            转写归档和仓库内容校验工具
```

回放、短视频制作资料和生成媒体留在本地，不提交 GitHub。数据字段、身份与网站读取约定见 [内容数据约定](events/data-contract.md)。

## 参与协作

欢迎通过 Issue 提出更正，或 Fork 仓库并提交 Pull Request。整理时标明期数与来源，保留分享者署名；不要公开未获授权的个人信息、资料或密钥。

仓库公开不代表所有内容可以任意转载或改编。发布前核对具体稿件、剪辑与参与者授权，见 [内容制作流程](docs/content-workflow.md)。
