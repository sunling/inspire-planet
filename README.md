# 启发星球 · Inspire Planet

启发星球是一个持续分享真实生活、问题、尝试和变化的共同学习空间。

这个仓库保存大家共同创作的会议转写、分享纪要、金句与各平台文章／图文脚本，并提供从内容整理到图片渲染的协作工具。每位分享者保有自己的表达与署名；**内容公开与发布均以参与者授权为前提**。

## 如何参与内容制作

日常工作分为三步；按自己的任务进入对应说明，不需要先读完全部技术文档。

| 步骤 | 做什么 | 操作说明 |
| --- | --- | --- |
| **1. 下载与归档转写** | 已配置每周定时下载并直接提交到 `main`；必要时可手动运行，提交前会校验内容和写入范围 | [会议转写与归档](docs/meeting-content.md) |
| **2. 生成内容** | 从转写整理文章、纪要、金句及图文脚本，人工确认 | [内容制作流程](docs/content-workflow.md) |
| **3. 渲染与发布** | 用 GitHub Actions 或本地命令生成图片、检查后按授权发布 | [渲染与发布](docs/rendering.md) |

需要调整封面样式、图卡布局、字体或渲染器时，另见 [设计与本地维护指南](docs/design-editing.md)。这属于**按需维护**，不是每期必须完成的第四步。

## 浏览与使用内容

- [按期浏览会议资料](events/README.md)：查看各期转写、分享稿和金句。
- [当前活动信息](current.md)：查看经过确认的活动安排与参与信息。
- [AI skills](.agents/skills/)：协助整理公众号文章、分享纪要、金句、小红书与视频号内容。使用前请阅读 [AGENTS.md](AGENTS.md)。

## 仓库里有什么

```text
events/             每期原始转写、内容稿件、JSON 和封面配置
docs/               三步工作流及设计维护说明
.agents/skills/      内容整理的 AI skills
.github/workflows/   转写下载、校验与按需渲染的 GitHub Actions
scripts/            工作流使用的脚本与渲染器
```

本仓库只长期保存**可编辑的源内容与必要的授权素材**。渲染图片、预览和 ZIP 按需生成，不提交仓库。数据结构、字段与网站使用方式见 [内容数据约定](events/data-contract.md)。

## 参与协作

欢迎通过 Issue 提出更正，或 Fork 仓库并提交 Pull Request。整理时请标明期数、文件和来源，保留分享者署名；不要公开未获授权的个人信息、资料或密钥。

本仓库公开不代表所有内容可以任意转载或改编。具体操作、验证与授权约定以对应的 [内容制作流程](docs/content-workflow.md) 和 [渲染与发布指南](docs/rendering.md) 为准。
