# Inspire Planet Recap Examples

这个文件保存启发星球会议纪要打磨中最有代表性的 before / after。它不是每次都更新，而是精选少量样本，帮助下次更快判断什么是好的导语、结构、发言人段落、互动回应和结尾。

## 使用原则

- 只收特别典型、可复用的样本。
- 优先保存“为什么初稿不对”和“为什么改后更好”。
- 保持克制，建议长期只保留 5–10 个高质量例子。
- 所有内容必须能追溯到转写稿、日记或用户明确提供的信息。
- 涉及真实姓名、隐私、医疗、身体状态、具体住址等内容时，必须先做匿名化或泛化。

## 候选分类

### 导语
用于保存“真实临场感 / 会后整理视角 / 不把会后内容写成会前状态”的例子。

### 结构取舍
用于保存“从流水账改成有主题、有取舍的纪要”的例子。

### 发言人段落
用于保存“一个具体场景 + 2-4 个关键观点 + 必要回应”的例子。

### 互动回应
用于保存“保留能推动主题的回应，删掉寒暄和重复赞同”的例子。

### 资源进入分享语境
用于保存“资源名称写完整，并放在对应发言人的具体经历与触发关系中”的例子。

#### Before
```md
## 会议中提到的资源
- 《清醒的活》
- 《月亮与六便士》
- 脱不花与王潮歌的长谈
```

#### 问题
- 读者看见了资源名称，却不知道是谁提到、为什么提到，以及它怎样进入对方的生活。
- 为了列表完整，容易收录正文没有真正使用的资源。

#### After
```md
在香港读书时，一门小组合作的课程让她长期焦虑。那段时间，她一边徒步，一边读《清醒的活》，后来把目标从“拿到好成绩”换成“自洽地走完这段艰难时光”。
```

#### 为什么更好
- 资源和具体处境、思想转折属于同一条叙事线。
- 名称完整，但不会打断文章另起一份书单。

### 结尾与加入我们
用于保存“下期预告、腾讯会议 ID、后台回复关键词和社群邀请”的稳定写法。

### 去宣传稿 / 去总结腔
用于保存把过度拔高、鸡汤化、知识博主化的句子改回真实纪要语气的例子。
