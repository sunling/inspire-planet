# Inspire Planet 公众号 Learnings

这个文件记录启发星球公众号文章与封面打磨过程中沉淀出的偏好、常见问题和本期特殊判断。它是动态文件，比 `SKILL.md` 更常更新。
（2026-10-06 由 `inspireplanet-recap` 与 `inspireplanet-cover` 两个技能合并而来；历史记录原样保留。）

## 使用原则

- 只记录真实生成或打磨中出现过的纠正，不凭空总结。
- 区分长期偏好和本期特殊判断。
- 不因为一期会议的特殊情况就改写长期规则。
- 每条尽量短，避免把这里变成另一个冗长 skill。
- 一段时间后回看：反复出现的规则可以建议合并进 `SKILL.md`；特别典型的 before / after 可以移入 `EXAMPLES.md`。

## 适合记录的纠正类型

- 导语太假、太文艺、太像开场白，缺少真实临场感。
- 把会后日记或会后感受误写成会前状态。
- 参会 / 未参会状态表达不准确。
- 文章太像流水账，逐个罗列发言，缺少取舍和串联。
- 文章太总结、太拔高、太像宣传稿或知识博主文章。
- 发言人段落太长，关键观点没有压缩。
- 互动回应保留太多，影响文章密度。
- 资源脱离分享者语境，被统一堆到文末，影响阅读和理解。
- 加入我们结尾、会议时间、腾讯会议 ID 或后台回复关键词不一致。

## 状态标记

- `[new]` 新观察：刚出现一次。
- `[recurring]` 重复出现：已经出现多次，可能值得合并进 `SKILL.md`。
- `[merged]` 已合并：已经写入 `SKILL.md` 或 `EXAMPLES.md`。
- `[discarded]` 丢弃：后来发现只是本期特殊情况。

## 2026-07-10｜EP27 封面复盘（原 `inspireplanet-cover`）

### 本轮反复纠正
- [recurring] 书桌、咖啡、笔记本、窗边只能营造启发星球气质，无法自动代表文章内容。
- [recurring] 提示词如果从场景和道具开始，容易生成每期都相似的通用封面。
- [merged] 先提取文章的核心变化、冲突或动作，再寻找可见的空间关系表达它。

### 典型判断
- “一起把问题说清楚”的第一版只呈现两杯咖啡、录音笔和耳机，表达了对话，却没有表达“问题从模糊到清晰”。
- 修改后用纠缠的线和零散纸片逐渐分开、对齐并汇向一张清晰卡片，才让画面和标题、正文形成关系。

### 长期检查
- 删除标题后，如果画面可以无差别用于最近三篇文章，视觉命题仍然太通用。
- 不能依赖中文标题替底图解释主题；底图本身需要承担主要内容关系。
- 封面文字使用补充文章信息的副标题，不重复文章正式标题；默认只保存带字成品，不交付无字版本。

## 2026-10-06｜封面输出改为 JPEG（原 `inspireplanet-cover`）

### 本轮决定
- 封面成品一律存 JPEG（`quality=88`、`optimize`、`progressive`），不再存 PNG；分辨率不降（横版 ≥1920px，竖版 1080×1440）。

### 长期检查
- 同一张 1920px 封面，PNG ≈ 2 MB，JPEG q88 ≈ 0.25 MB，体积差 8–10 倍；手机端实测平均像素差 2/255，无可见差异。封面每期都进仓库，格式就是长期体积的唯一杠杆。
- 用 git 覆盖同名文件不会让仓库变小——历史保留每一版，`.git` 照常增长（实测：2 MB 的图覆盖 5 次，`.git` 从 2 MB 长到 10 MB）。想省体积只能在入库前把单张降下来，不要靠改名或覆盖。
- 保存前转 RGB 并合成底色；带 alpha 的图直接存 JPEG 会留下黑底或报错。

## 2026-10-06｜技能重组

### 本轮决定
- 公众号的「文章 + 标题/摘要 + 横版封面」收进本 Skill，`inspireplanet-recap`、`inspireplanet-promo`、`inspireplanet-cover` 三个技能取消。
- 发布信息块放文章**末尾**，文件顶部保持干净，方便整段粘进编辑器。
- 二维码插入位从 `index.md` 移到 `gzh-{slug}.md`——`index.md` 是仓库内材料、不对外发布，原先它承担二维码落点没有实际用途。
- 封面设计原则与 JPEG 规范抽到 `../inspireplanet/references/cover-design.md`，与小红书共用，避免两份漂移。

### 长期检查
- 判断一个技能该不该拆，看的是**交付物**而不是**动作**：一个 skill 对一个文件，不要为同一个交付物设多个接力技能、再用中间文件当交接台。
