# Inspire Planet Promo

## 目标

为某一期启发星球会议纪要准备**公众号**发布辅助材料，但不把编辑说明和社交文案混入会议纪要正文。

小红书图文材料由 `inspireplanet-xhs` 生成到 `xiaohongshu.md`，视频号材料由 `inspireplanet-sph` 生成到 `shipinhao.md`，本 Skill 不重复产出。

## 路径

活动目录：

```text
events/{year}/{YYYYMMDD}-epXX/
```

优先输入：

```text
recap.md
```

备选输入：

```text
transcript.txt
```

默认输出：

```text
promo.md
```

规则：

- `recap.md` 已存在时，以纪要为主要输入；
- 纪要尚未生成、用户明确只需要公众号文案时，可以从 transcript 生成 `promo.md`；
- 不因为缺少纪要而创建一个只含发布文案的 `recap.md`；
- 已有 `promo.md` 时更新原文件，不创建 `promo-v2.md` 或把同一内容复制到多个文件；
- 小红书和视频号的材料不写进 `promo.md`。

## 当前运营信息

发布文案需要活动时间、会议平台、加入方式或邀请语时，按以下顺序读取：

1. 用户当前对话中的明确说明；
2. 当前 event 中的真实活动文件；
3. `current.md` 中仍然有效、带验证日期的信息；
4. 找不到时省略或标记待确认。

`current.md` 为 `status: needs-verification` 时，不得把待确认内容当作当前事实写入文案。

## 默认产出

- 120 字以内公众号摘要；
- 5–10 个自然、不标题党的公众号标题建议；
- 3–5 条公众号横版封面副标题候选；
- 用户需要时提供公众号合集分类建议。

## 公众号标题

- 可以保留较完整的问题、关系和思考转折，长度不必迁就短内容平台；
- 自然、准确、有阅读入口，不制造冲突，不写知识博主式结论；
- 默认沿用纪要里最真实的核心问题或张力。

## 公众号封面副标题

- 默认 6–14 个中文字符；
- 用于约 `2.35:1` 的公众号横版封面，补充公众号主标题而不是重复主标题；
- 每条都应能转换成当期独有的视觉命题，避免“关于成长的思考”等通用表达。

## 与封面 Skill 的交接

`inspireplanet-promo` 负责提供副标题候选，不决定最终画面。

`inspireplanet-cover` 负责：

- 从候选中选择或克制调整最终副标题；
- 设计视觉命题并生成封面；
- 将最终选择、视觉命题、提示词和成品路径写回 `promo.md` 的“公众号封面配置”部分。

若用户只运行 cover Skill、还没有 `promo.md`，cover 可以创建一个只含公众号封面配置的最小 `promo.md`。

## Markdown 结构

```md
# EPXX 发布辅助材料

## 公众号摘要
{120 字以内}

## 公众号标题建议
1. ...

## 公众号封面副标题候选
- ...

## 公众号合集分类建议
{用户需要时保留，否则省略}

## 公众号封面配置
- 最终副标题：
- 视觉命题：
- 生成提示词：
- 成品路径：
```

公众号封面尚未生成时，可以省略“公众号封面配置”，不要填空占位。

## 边界

- 所有事实和人物观点必须来自 recap、transcript 或其他明确可追溯材料；
- 不制造冲突、不夸大结论、不写喊话式口号；
- 摘要准确概括本期，不用“这一次我们聊了很多”等空话；
- 不在 `promo.md` 中新增纪要正文没有支持的事实；
- `promo.md` 是发布辅助材料，不是另一篇会议纪要。

## 完成后的回复

简短说明：

1. 使用了 recap 还是 transcript；
2. 创建或更新的 `promo.md` 路径；
3. 推荐的首选标题和副标题候选；
4. 哪些事实、时间、链接或活动信息仍需确认。
