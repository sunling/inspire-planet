# Inspire Planet Promo

## 目标

为某一期启发星球会议纪要准备发布辅助材料，但不把编辑说明和社交文案混入会议纪要正文。

## 路径

活动目录：

```text
events/{year}/{YYYYMMDD}-epXX/
```

优先输入：

```text
recap.md
```

备选输入：

```text
transcript.txt
```

默认输出：

```text
promo.md
```

规则：

- `recap.md` 已存在时，以纪要为主要输入；
- 纪要尚未生成、用户明确只需要发布文案时，可以从 transcript 生成 `promo.md`；
- 不因为缺少纪要而创建一个只含发布文案的 `recap.md`；
- 已有 `promo.md` 时更新原文件，不创建 `promo-v2.md` 或把同一内容复制到多个文件。

## 当前运营信息

发布文案需要活动时间、会议平台、加入方式或邀请语时，按以下顺序读取：

1. 用户当前对话中的明确说明；
2. 当前 event 中的真实活动文件；
3. `current.md` 中仍然有效、带验证日期的信息；
4. 找不到时省略或标记待确认。

`current.md` 为 `status: needs-verification` 时，不得把待确认内容当作当前事实写入文案。

## 默认产出

- 120 字以内公众号摘要；
- 5–10 个自然、不标题党的公众号标题建议；
- 3–5 条公众号横版封面副标题候选；
- 5–8 个符合小红书阅读语感的小红书标题建议；
- 3–5 条适合小红书封面图的短副标题候选；
- 约 200–300 字小红书或视频号帖文；
- 一组小红书图集脚本（封面 + 6–10 页内页，每页一句大字 + 一句小字 + 图片建议）；
- 5 个话题词；
- 用户需要时提供公众号合集分类建议。

## 两套标题与副标题

### 公众号标题

- 可以保留较完整的问题、关系和思考转折，长度不必迁就小红书限制；
- 自然、准确、有阅读入口，不制造冲突，不写知识博主式结论；
- 默认沿用纪要里最真实的核心问题或张力。

### 公众号封面副标题

- 与小红书封面副标题分开生成，默认 6–14 个中文字符；
- 用于约 `2.35:1` 的公众号横版封面，补充公众号主标题而不是重复主标题；
- 可以比小红书副标题多保留一层变化或动作，但仍要短、清楚、适合手机端阅读；
- 每条都应能转换成当期独有的视觉命题，避免“关于成长的思考”等通用表达。

### 小红书标题

- 与公众号标题分开生成，不把公众号标题直接截短；
- 每条都使用 `{year}EP{episode} - ` 前缀，例如 `2026EP28 - `；
- **包含前缀、空格、连字符和标点在内，总长度不得超过 22 个字符**；生成后必须逐条计数校验；
- 更贴近小红书的阅读语感，可以使用第一人称、具体困惑、反差或提问，例如“我为什么总在比较”；
- 保留真实感和克制，不使用“震惊”“一定要看”“彻底改变”等夸张钩子，也不制造纪要中不存在的焦虑或答案。

### 小红书封面副标题

- 每条 **5–8 个中文字符**，用于生成小红书封面图；
- 不加期数前缀，不写成长句，不使用逗号、句号等句内标点凑长度；
- 抓住一个动作、变化或矛盾，如“把选择拿回来”，不要概括整期内容；
- 各候选尽量覆盖不同角度，避免只是替换近义词。

### 小红书图集脚本

为小红书图文（图片合集）生成逐页脚本，是「同一期多形态」里较轻的一档。

- 默认 6–10 页，第 1 页为封面，末页为邀请；
- 每页只给三样：图上大字、小字、图片建议；文字总控制在一屏可读；
- **首图落在具体的人与事上**（时间、动作、场景），不放抽象金句或结论；
- 内页走一条叙事弧：处境 → 细节 → 转折 → 一句原声收尾；不并列堆砌金句；
- 末页用一个问题作邀请，落款「启发星球笔记」；
- 内容全部来自 recap / transcript，不虚构现场；
- 图片优先真实照片（当事人提供）；缺照片时按页降级为氛围图或手写摘录卡；
- 涉及真实他人的个人经历时，按授权状态处理：已确认可发布的使用真实人名，未确认的先标注并给出匿名化改法。
- 图集脚本写好后，可用 `scripts/render-cards.py` 直接渲染成卡片 PNG（暖纸摘录风，无需浏览器；大字默认马善政毛笔楷书，可用 `big_font` 切 `kai`/`klee`，小字用霞鹜文楷）。

## 与封面 Skill 的交接

`inspireplanet-promo` 负责提供副标题候选，不决定最终画面。

`inspireplanet-cover` 负责：

- 从候选中选择或克制调整最终副标题；
- 设计视觉命题并生成封面；
- 将最终选择、视觉命题、提示词和成品路径写回 `promo.md` 的“公众号封面配置”部分。

若用户只运行 cover Skill、还没有 `promo.md`，cover 可以创建一个只含公众号封面配置的最小 `promo.md`。

```md
# EPXX 发布辅助材料

## 公众号摘要
{120 字以内}

## 公众号标题建议
1. ...

## 公众号封面副标题候选
- ...

## 小红书标题建议
1. {year}EP{episode} - ...

## 小红书封面副标题候选
- ...

## 小红书图集脚本
{逐页：图上大字 / 小字 / 图片建议}

## 小红书 / 视频号文案
{约 200–300 字}

## 话题词
#话题一 #话题二

## 公众号合集分类建议
{用户需要时保留，否则省略}

## 公众号封面配置
- 最终副标题：
- 视觉命题：
- 生成提示词：

```

公众号封面尚未生成时，可以省略“公众号封面配置”，不要填空占位。

## 边界

- 所有事实和人物观点必须来自 recap、transcript 或其他明确可追溯材料；
- 不制造冲突、不夸大结论、不写喊话式口号；
- 摘要准确概括本期，不用“这一次我们聊了很多”等空话；
- 公众号标题和小红书标题分别生成，不用同一套候选兼顾两个平台；
- 公众号封面副标题和小红书封面副标题分别生成，不互相截短或复用；
- 公众号封面副标题默认 6–14 个中文字符，并能承担当期独有的视觉命题；
- 小红书标题含固定前缀后不得超过 22 个字符；
- 小红书封面副标题必须为 5–8 个中文字符，简短、可上图；
- 社交帖文保留具体的人、经历和问题，不压缩成泛成长文案；
- 图集脚本首图必须落在具体的人与事上，不使用抽象金句；
- 图集脚本涉及真实他人的个人经历时，按授权状态处理：已确认可发布的使用真实人名，未确认的标注授权需求并给出匿名化改法；
- 不在 `promo.md` 中新增纪要正文没有支持的事实；
- `promo.md` 是发布辅助材料，不是另一篇会议纪要。

## 完成后的回复

简短说明：

1. 使用了 recap 还是 transcript；
2. 创建或更新的 `promo.md` 路径；
3. 推荐的首选标题和副标题候选；
4. 哪些事实、时间、链接或活动信息仍需确认。
