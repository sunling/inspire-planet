# Inspire Planet 视频号

## 目标

把某期会议里**一位分享者的一件事**，做成视频号的**图文**内容（多张图 + 文字），进入微信生态传播。

不做视频/原声：腾讯会议云录制只能人工下载（见文末实测），而图文同样能承载“人和事”，还更省事。

## 选题与排期

- **不要求覆盖每一位分享者**；一期只挑值得单独发的 1–2 位；
- **各渠道独立挑人**：视频号挑的人不必和小红书、公众号相同；
- 挑选标准：这件事能不能自成一件事、有没有具体场景、脱离上下文能不能读懂；
- 发布节奏：同一渠道**每隔一天发一条**，不要一天连发；顺序写进文件开头的 `## 发布排期`。

```md
## 发布排期
| 顺序 | 篇目 | 建议发布 |
|---|---|---|
| 1 | {分享人} · {题眼} | 第 1 天 |
| 2 | {分享人} · {题眼} | 第 3 天 |
```

## 平台规格（来自视频号帮助中心）

- 图片数量：手机端 1–20 张；电脑端「视频号助手」可上传 18 张，**超过 18 张会变成视频**；
- 图片宽高比（宽/高）必须在 `0.33 ~ 3.0` 之间；不支持 GIF；
- 文案最多 1000 字；**描述超过三行会自动折叠** —— 所以前 3 行必须能独立成立；
- 本项目卡片为 1080×1440（比例 0.75），在合规范围内，可直接用。

## 与小红书的关系

同一期的同一件事，**图片可以共用**（都走 `scripts/render-cards.py`）。差别只在文案：

| | 小红书 | 视频号 |
|---|---|---|
| 标题 | 短，逐字稿里的原话感 | 可稍完整 |
| 正文 | 短，带话题 | 可长到 1000 字，前 3 行是钩子 |
| 图片 | 图集脚本 | 同样的图，≤18 张 |

所以一期做完小红书材料后，视频号通常只是**换一套文案**，不用重新画图。

## 工作流程

1. **下载逐字稿**：本期目录还没有 `transcript.txt` 时，先走 `inspireplanet-transcript`；
2. **生成 `sph-{slug}.md`**：标题、正文、图片脚本、话题词；
3. **渲染成图**（人工触发）：复用小红书那套卡片，见「渲染成图」；
4. **手动发布**：电脑端「视频号助手」（channels.weixin.qq.com）→ 内容管理 → 图文 → 发表图文。

## 路径

活动目录：

```text
events/{year}/{YYYYMMDD}-epXX/
```

优先输入：

```text
transcript.txt
gzh-{slug}.md
```

默认输出：

```text
sph-{slug}.md
```

规则：

- **一位分享者一个文件**：`sph-{slug}.md`（如 `sph-liying.md`），一条一个人一件事；本期只写挑中的那几位；
- 文件开头保留 `## 发布排期`（见「选题与排期」）；
- 已有同名文件时更新原文件，不创建 `sph-liying-2.md`；换一位分享者就新建对应的 `sph-{slug}.md`；
- 公众号材料不写进本文件（那是 `gzh-{slug}.md`）。

## 默认产出

- 1 个标题；
- 正文 ≤1000 字，**前 3 行独立成立**（折叠后仍能读懂）；
- 图片脚本：逐页文字，页数 ≤18；
- 3–5 个话题词。

## 正文写法

- 前 3 行是钩子：具体的人、具体的场景，不用"这一期我们聊了很多"这类引入；
- 中段按"一件事"的起承转合走，允许保留口语与不确定的部分；
- 结尾不喊口号，可以留一个真实的问题；
- 话题词 3–5 个，不堆砌。

## Markdown 结构

一期多条时，每条一个 `##` 小节；图片脚本小节名用 `### 图片脚本`（渲染脚本认「脚本」二字）：

```md
# EPXX 视频号图文材料

## {人名} · {一件事}

### 标题
{标题}

### 正文
{≤1000 字；前 3 行独立成立}

### 图片脚本
#### 第 1 页
- 图上大字：...
- 小字：...
- 左上署名：...

### 话题
#... #...
```

## 渲染成图

与小红书共用同一套卡片（暖纸摘录风，无需浏览器）：

```bash
python3 scripts/render-cards.py events/{year}/{YYYYMMDD}-epXX/sph-{slug}.md out_dir/
```

- 大字默认马善政毛笔楷书，小字霞鹜文楷；页标题含"原声"自动深色；字体首次运行自动下载；
- **卡片图不进仓库**：仓库只保留 `sph-{slug}.md`（图上的文字），随时可以重渲。

## 附：为什么不做原声视频

云录制只能人工下载，已实测结论：

- `tmeet record address` 走 `/v1/mcp/addresses`，只返回 `view_address`（网页，页面里没有直链）；
- 官方 `GET /v1/addresses/{record_file_id}` 本可返回 `download_address`(mp4) / `audio_address`(m4a)，但 tmeet 未暴露，其 OAuth token 加密保管、读不出来 —— **自动化下载暂不可行**，别在这上面反复试；
- 若以后要做视频：整场录制约 1.3GB / 80 分钟，只为取 60–90 秒，剪完即删源；或请分享者自己录一段（更真实）。

## 署名与授权

已确认可以发布的，使用真实人名；未确认的先标注，并给出匿名化改法。

## 边界

- 所有事实、人物经历必须来自 `transcript.txt` 或 `gzh-{slug}.md`，不虚构；
- 生成内容与发布分开：**本流程不做平台发布自动化**，发布由人手动完成。

## 完成后的回复

简短说明：

1. 使用了 transcript 还是 recap；
2. 创建或更新的 `sph-{slug}.md` 路径；
3. 本期挑了谁（以及为什么没写其他人）、建议的发布顺序；
4. 哪些地方仍需确认。
