# Inspire Planet 视频号

## 目标

把某期会议里**一位分享者的一段真实原声**，做成一条可以在视频号发布的竖版视频 + 文案。

视频号最有价值的资产是**原声**：会议有云录制，所以优先取一段真实发言做视频，而不是把文字卡拼成幻灯片。

## 工作流程

1. **下载逐字稿**：本期目录还没有 `transcript.txt` 时，先走 `inspireplanet-transcript`；
2. **下载本期云录制**（人工）：`tmeet record address --meeting-record-id <id>` 只返回一个**查看地址**（网页，不是直链），需要人工下载一次 mp4 到本机；
3. **生成 `shipinhao.md`**：标题、文案、封面文字、视频脚本（选哪一段、时间轴、字幕、卡片文字）；
4. **渲染出片**（人工触发）：用 `ffmpeg` 合成竖版视频。

## 路径

活动目录：

```text
events/{year}/{YYYYMMDD}-epXX/
```

优先输入：

```text
transcript.txt
recap.md
```

默认输出：

```text
shipinhao.md
```

规则：

- 一期可以有多条视频，**一条讲一个人的一件事**；
- 已有 `shipinhao.md` 时更新原文件，不创建 `shipinhao-v2.md`；
- 公众号材料不写进本文件（那是 `promo.md`）。

## 默认产出

- 1 条视频号标题；
- 约 150–250 字视频号文案（结尾带话题词）；
- 封面文字：一行大字 + 一行小字；
- **视频脚本**：发言人、逐字稿时间码、起止时间、逐句字幕稿、要叠的卡片文字、建议时长；
- 3–5 个话题词。

## 选段原则

- 选"一个人讲一件事"的完整小段，能在 60–90 秒里自成起承转合；
- 优先有具体场景和细节的段落，不选抽象金句；
- 字幕**尽量不改写原声**，只删口头重复；不改变立场、语气与不确定的部分；
- 涉及他人隐私、未经同意收录的声音或画面不选。

## 渲染成视频

本机已具备：`ffmpeg`（系统自带，无需 root）。做法：

- 画面 1080×1920 竖版；背景可用暖纸文字卡（复用 `scripts/render-cards.py` 的卡片）或当期真实照片；
- 声音取云录制里截出的原声（`ffmpeg -ss ... -to ...`），需要时加低音量背景音乐；
- 字幕：把字幕稿烧进画面，或用卡片逐句替换；
- **视频文件不进仓库**：仓库只保留 `shipinhao.md`（文案 + 字幕稿），随时可以重渲。

渲染脚本尚未纳入 `scripts/`；需要时先补 `scripts/render-video.py`。

## 署名与授权

已确认可以发布的，使用真实人名；未确认的先标注，并给出匿名化改法。

## 边界

- 所有事实、时间码、人物经历必须来自 `transcript.txt` 或云录制，不虚构；
- 不使用未授权的他人声音、画面；
- 生成内容与发布分开：**本流程不做平台发布自动化**，发布由人手动完成。

## 完成后的回复

简短说明：

1. 使用了 transcript 还是 recap；
2. 创建或更新的 `shipinhao.md` 路径；
3. 推荐的选段（谁 / 时间码 / 时长）与封面文字；
4. 哪些地方仍需确认。
