# 启发星球播客

一期会议对应一集播客。默认采用用户已确认的 MVP：保留现场介绍、自然道别、原始分享顺序与讨论，不额外加片头片尾、AI 配音或音乐，不追求固定时长。用户另提风格或剪辑要求时按本次要求调整。当前暂时只面向小宇宙，渠道安排读取 `current.md`。

## 素材与存放

先读仓库 `README.md`、`current.md`、本期真实转写和 README 发布备注。会议事实来自当期转写与回放，文章及纪要只辅助理解；原始转写不润色。核对声音内容、日期与期次，不能只凭文件名判断。

沿用用户的本地回放位置，不移动或覆盖源文件。有音频直接使用音频；视频也可提取音轨。缺素材时只请求本地路径，不自动下载公开转写或上传会议音频。

制作资料放在被 Git 忽略的 `replays/`，例如 `replays/{year}/{date}-epXX-podcast/`；已有目录继续使用。写入前检查 `git check-ignore`。识别结果、剪辑单、发布草稿、内部备注和媒体导出留在本地；最终发布文字获准公开后可按下文归档，媒体不提交 GitHub。公开流程文档只放通用规则，不带真实私人路径和片段内容。

## 编辑

1. 检查实际媒体与现有识别结果，先复用已有本地环境和定位信息。按需用本地语音识别定位开场、各话题、结尾和候选删减。工具与格式见 [本地工具](references/tools.md)。
2. 清理开场等待、设备／共享屏幕调试、结尾报名事务、明显重复起句和明确长空白。保留有作用的回应、笑声、思考、否定、条件和不同观点，不按词表批量删“嗯”“对”“然后”，不跨段制造新结论。
3. 在实际声音附近核对每个切点，留够句首句尾和自然停顿。转写时间不是媒体切点，不用整场固定偏移代替逐段定位。静音检测只给候选，低音量可能包含声音；确认候选是空白后再决定缩短，通常保留约 1.2 秒，也可按语境调整。
4. 写本地 `edit-plan.json`，每处删除记录源媒体秒数、理由和定位依据；章节起点也用源媒体秒数。已授权的整期 MVP 可直接轻剪，无须逐刀再请用户批准；新增敏感内容范围或显著重组另行核对。
5. 导出后检查开头结尾、剪接处和各人音量；生成整集解码、时长与响度报告。脚本结果不代替听审，准确说明已做的局部识别、技术验证及未完成的听审。

## 本地交付

- `export/podcast.m4a`：本期轻剪试听稿，保留源文件。
- `show-notes.md`：标题、简洁简介、参与者、成品时间轴、本期详情页链接、固定加入二维码图片与内部待核对事项。发布文本和内部记录分区，复制发布时不混入编辑备注；不补写不确定人名、书名、活动安排。两个入口按下节分别核对，不以文字“已插入图片”代替实际图片素材。
- `edit-plan.json`：删减依据；`export/chapters.json`、`chapters.txt`：映射后的成品时间轴；`export/report.json` 和日志：技术检查。章节不能指向已删除内容。

## Show notes 的内容与加入入口

1. **本期详情页链接**：用于继续阅读回顾、看金句与回应。采用用户提供、当期 README 已记录或实际打开核实过的链接；不凭年份和期数猜路径。发布前检查可以访问且期次正确。回顾尚未完成时，可链接已经存在、可用的简洁本期页，之后在同一地址补内容。页面不存在或不可用时，列为待补项，不把无效或占位链接混进正式稿；创建或修改站点另按站点任务处理。
2. **固定加入二维码图片**：复用用户已确认的“扫码进入 `https://inspireplanet.cc/join`”图片，图片旁简短说明“扫码加入启发星球，获取最新微信群二维码”。它指向站点加入页，加入页展示管理员维护的最新普通微信群二维码。不要直接嵌入会过期的微信群二维码，也不要误用分享者群二维码。
3. 从 `current.md`、当期授权素材或已核实项目资源取得该固定图片，核对扫码目标确为 `/join`。目前若只有目标地址、没有图片文件或公开图片地址，明确列为缺失素材，不猜图片路径、不拿动态群二维码顶替。制作稿可引用本地素材；正式归档不带私人路径，使用可公开的图片引用。
4. 保留一个主要内容链接（本期详情页），固定加入二维码是独立的参与入口；不再堆放首页、社群文字链接、多个卡片链接或其他期播客链接。二维码已正常显示时不重复放 `/join` 文字链接。
5. 实际发布时核对平台编辑器是否支持图片，以及发布预览中的图片能否显示、扫码目标是否正确。已核实平台不能插图时说明限制，以 `/join` 的文字链接作为备用，不声称已嵌入图片；暂时找不到图片文件不等于平台不支持插图。固定二维码的目标地址不随微信群二维码轮换；平台里的图片仍须在首次使用时验证。

先交付可完整阅读的简介和时间轴，再放以上两个用途清楚的入口。不要求听众必须进入网站才能看懂节目简介。

## 小宇宙发布与文字归档

用户试听并确认声音、署名和具体内容的公开范围后，再在小宇宙上传音频、填写标题、简介、成品时间轴、本期详情页与固定加入二维码并核对预览；只有用户明确要求时才代操作。平台账号与节目设置、当前上传要求在实际发布时核实，不猜测技术限制或主页链接。

获准公开后，将本地 `show-notes.md` 的最终发布部分整理成 `events/{year}/{YYYYMMDD}-epXX/podcast.md`，只保留正式标题、简介、参与者、成品时间轴、本期详情页，以及实际使用的可公开固定加入二维码图片引用（平台不支持插图时保留实际使用的加入页备用链接）；发布后在“发布信息”中补真实小宇宙链接、实际音频时长与发布日期，在本期 README 加导航。去掉内部核对记录、私人路径及未获准公开的信息，不能整份复制制作稿。`podcast.md` 作为长期正式稿，不与本地稿长期双份维护；媒体重剪时同步更新时间轴。没有公开授权时继续只交本地稿，不创建占位公开文件。

把发布回填作为交接点：用户选择完整会后流程时，先完成本期页核实、播客制作与发布，拿到真实播客链接后，再交 `inspireplanet-summary` 和 `inspireplanet-cards` 制作回顾、金句及一条群消息。群里仍只发一个片段和本期详情页入口。用户只做文字或播客暂缓时可先出文字，未发布的播客信息保持缺失，不虚构链接。

在当期 `podcast.md` 的“发布信息”维护一份正式记录：

- 播客链接：实际发布的单集链接，未发布时不填写。
- 实际时长：发布音频的时长，不从源回放或转写结尾估算。
- 发布日期：实际发布日，不把制作日或会议日当作发布日。
- 本期详情页：已核实的同一期页面。
- 固定加入二维码：实际使用的可公开图片引用，扫码目标为 `/join`；若平台不支持插图，则保留本次实际使用的加入页备用链接。

这些记录供后续处理读取；该归档不代表网站已经支持播客展示。页面显示播客入口要核实站点功能，不能仅因写了 `podcast.md` 就对读者声称“回顾页里可以收听”。详细存放规则见 [内容制作流程](../../../docs/content-workflow.md)。

官网与加入入口使用 `current.md` 和当期已核实信息，按上述规则区分内容链接与固定加入二维码。交付可播放的音频及文案链接，说明实际时长、删减取舍、听审状态与待确认公开范围。试听认可不自动等于声音、署名、家人或他人经历的公开授权；不自动发布、改站或提交媒体。

改动公开文件后运行 `python3 scripts/check-content.py`。
