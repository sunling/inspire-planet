# 封面设计原则与保存规范

## 设计原则

- 不只表现“开会、阅读、成长”这种题材类别；
- 咖啡、电脑、笔记本、耳机和窗边不是默认答案，只有能承担核心关系时才用；
- 不生成可识别真人，不虚构真实现场；
- 只做带字成品，不创建、不保存、不交付无字版本；
- 主体文字只放最终副标题；副标题补充主标题的信息，不照抄、改写或重复主标题；
- 副标题优先表达本篇独有的问题、变化、张力或行动，避免“关于成长的思考”这类通用文案；
- 不出现 Logo、水印、伪文字和营销海报感；
- 删掉文字后，若画面可以无差别用于最近三期，说明太通用，重做。

## 出图流程

1. 完整读文章，提取本篇独有的核心变化、问题或动作；
2. 选定最终副标题（字数见各渠道 Skill）；
3. 把它转换成一句可见的空间关系或动作（视觉命题）；
4. 按渠道尺寸构图，加入中文副标题，只输出一张完整的带字封面；
5. 检查文字准确、完整、清晰，且不与主标题表达相同信息；不合格就重做；
6. 按下面的规范存 JPEG，并回报实际体积。

## 保存规范（JPEG）

- 一律 JPEG，不交付 PNG；
- 参数：`quality=88`、`optimize=True`、`progressive=True`；
- 保存前转 `RGB`；带 alpha 的先合成到设计底色，不留透明通道；
- 分辨率按渠道要求，不降；
- 单张目标 ≤400 KB；超出先降到 `quality=85`，再把 `subsampling` 设为 `2`（4:2:0），仍超出再缩到宽 1600px；
- 保存后打印实际体积，超过 500 KB 视为不合格，重存。
