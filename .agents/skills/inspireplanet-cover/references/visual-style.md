# 暖色手绘系列视觉规范

- 画幅：约 2.35:1 横版，适合公众号主封面；不承诺兼容所有裁切，上传后仍核对平台预览。可支持时使用接近该比例的高清输出，不强行拉伸。
- 底色：暖米白，细腻纸张颗粒；主文字深森林绿，辅色鼠尾草绿、赭黄、少量暖橙。参考色 #F5EBDD、#203C23、#8A9570、#D58A36，允许自然水彩变化。
- 介质：细腻水彩与彩铅手绘，温暖日光和柔和阴影；有生活细节但不杂乱。面向成人的文学杂志插画，不做幼儿卡通或写实商业广告。
- 版式：左侧约 50–58% 为文字和米白留白，右侧为叙事插画，边缘自然过渡。主标题最大；期数在左上，署名在左下；四周保留约 5% 安全边距。
- 字体：深绿、清晰、有书卷气的中文展示字体，与系列案例协调。避免花体、过细笔画和高强度发光；标题缩小后仍清楚。
- 场景：从正文的真实动作或可明确识别为象征的场景出发，优先阅读、交谈、观察、尝试等日常瞬间。人物只是示意，不推测作者的性别、年龄、外貌或家庭成员；细节未说明时使用背影、局部手部、远景或物件构图。
- 情绪：安静、有好奇心、温暖、允许事情尚未想清楚。不得用奖杯、金钱雨、上升箭头、胜利姿态、励志口号替代正文。
- 文字：逐字提供标题、品牌、期数、署名；英文只在正文核心需要时出现，并检查拼写。不要生成可扫描二维码、仿真标志或额外无关文字。
- 统一视觉语言，不重复套用同一桌面、路口或校园。不同文章各有一个清楚的主场景。
