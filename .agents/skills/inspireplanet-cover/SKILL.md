# 启发星球文章封面

## 输入与触发
读取最终文章、当期期数、年份与获准署名；仓库任务先读根目录 AGENTS.md、README.md、current.md 及本期发布备注。用户直接提供文章时，以该正文为依据，无须重新改写文章。
完成整篇文章交付后默认制作一张封面；用户要求仅文字、选题讨论、未完成片段，或只修改错字、摘要时不生成。已有符合当前正文的封面时复用；主题、标题或署名改变时再判断是否更新。
读取 [视觉规范](references/visual-style.md) 和 [参考案例](references/examples.md)。

## 制作
1. 从正文选出一个具体经历、动作或问题。保留探索和不确定性，不把问题写成成功结论。用一个主场景表现，不拼成全篇内容清单。
2. 提炼自然的封面短标题，通常 10–22 个汉字，按阅读节奏分 2–3 行。允许为排版缩短发布标题，但不得改变原意；正文发布标题保持不变。年份、期数及署名有冲突时先核对，缺失时询问，不猜。
3. 直接生成一版，不要求用户预先选方案。固定小字为“启发星球 · {年份} EP{期数}”，底部署名为“分享者｜{名字}”。副标题仅在帮助理解时增加一行；不默认加入网址、二维码或额外标语。当前这一系列样例不放域名，优先于旧的通用封面底部域名安排。
4. 使用当前环境的图像生成工具，默认内置 imagegen；若有适用的图像生成 skill，先遵循其调用规范。不能只返回提示词、SVG 或工具编辑页冒充成图。不因缺少工具自动改用收费 API；说明阻碍并保留可复用的设计说明。
5. 构造完整提示词，写入画幅、配色、手绘介质、留白、具体场景、逐字文案及禁用项。使用参考图时明确只参考视觉风格，不复制人物或场景；插画人物不是分享者真实肖像。
6. 检查生成结果：中文标题、期数、署名和英文拼写准确；字不裁切；缩小后仍可读；场景符合正文且不暗示虚构经历；人物与手部无明显异常。发现错误时只针对问题修订并复检。
7. 展示最终图，简短说明标题。按当前环境的交付和持久保存规则保存；只有实际生成并检查图片后才报告完成。

## 仓库归档与边界
技能规范可提交仓库。成图和内部提示词默认留在被忽略的 replays/{当期目录名}/covers/，文件名 gzh-{slug}-cover-v1.png；更新用 v2 等，不覆盖已审阅版本。没有本地运行环境时遵循宿主保存规则，明确图已交付但未入库。
用户明确要求将成图公开归档后，可保存到当期 covers/，并仅在真实文件存在后更新本期 README。不要把图片路径或提示词塞进文章文末发布信息；不要创建空参考图文件或虚构素材链接。
这是一套 agent 执行流程，不是 GitHub 文件监听器。未配置并验证独立执行器前，不宣称 push 后自动生图；不新增付费 API、密钥、Actions 或自动发布。仓库 skill 的保存不等于已安装到 ChatGPT 个人技能目录。
