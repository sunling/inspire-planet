# Inspire Planet Recap Learnings

这个文件记录启发星球会议纪要打磨过程中沉淀出的偏好、常见问题和本期特殊判断。它是动态文件，比 `SKILL.md` 更常更新。

## 使用原则

- 只记录真实生成或打磨中出现过的纠正，不凭空总结。
- 区分长期偏好和本期特殊判断。
- 不因为一期会议的特殊情况就改写长期规则。
- 每条尽量短，避免把这里变成另一个冗长 skill。
- 一段时间后回看：反复出现的规则可以建议合并进 `SKILL.md`；特别典型的 before / after 可以移入 `EXAMPLES.md`。

## 适合记录的纠正类型

- 导语太假、太文艺、太像开场白，缺少真实临场感。
- 把会后日记或会后感受误写成会前状态。
- 参会 / 未参会状态表达不准确。
- 文章太像流水账，逐个罗列发言，缺少取舍和串联。
- 文章太总结、太拔高、太像宣传稿或知识博主文章。
- 发言人段落太长，关键观点没有压缩。
- 互动回应保留太多，影响文章密度。
- 资源脱离分享者语境，被统一堆到文末，影响阅读和理解。
- 加入我们结尾、会议时间、腾讯会议 ID 或后台回复关键词不一致。

## 状态标记

- `[new]` 新观察：刚出现一次。
- `[recurring]` 重复出现：已经出现多次，可能值得合并进 `SKILL.md`。
- `[merged]` 已合并：已经写入 `SKILL.md` 或 `EXAMPLES.md`。
- `[discarded]` 丢弃：后来发现只是本期特殊情况。
