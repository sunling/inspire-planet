# EP38｜孙玲：我做了一个工具，让想法更容易留下来

口述｜孙玲　整理｜启发星球

九月二十二日，我在西雅图的一场 Women in AI 活动上，演示了自己做的一个小工具。现场要用英文，五分钟讲完。我知道自己做了什么、为什么做，也尽量把它说清楚，但五分钟实在很紧。回到中文的交流里，我可以慢一点解释：我想解决的，是怎样把此刻想记录的东西留下来。

有时，我突然有一个灵感；有时，我只想花几分钟记一下今天。我不想每次都先打开电脑、创建文件夹、创建文件，再开始写。这些琐碎的工作，可以交给工具。我要做的，是把自己的想法留下来。

我从二〇〇九年开始记录。以前不是每天都记，最近几年基本上天天都有自己的记录。印象笔记、有道云、石墨文档、语雀、Notion，我都用过。现在，我用 AI 聊天工具，加上自己做的小工具，把记录存到 GitHub 的仓库里。用语音转成文字，也可以很快记下一段。

记录对我来说，首先是梳理想法。有些心思，说出来、写下来，才会更清楚。它也让我以后能够回看：那时候遇到了什么人，看到了什么事，在想什么。我觉得这有点像在写自己的历史。如果未来想做一些输出，我也知道可以到哪里去找。

在 AI 的使用里，这些记录还提供了个人的背景。一般的回答可能很泛，而我自己的经历、喜好、笔记，能让对话多一点上下文。这是我鼓励记录的一个原因。不过，每个人对隐私的接受程度不同，有担心完全可以理解。这是个人选择，我只是提供一种可能性。

我的工具可以存下日记、笔记，之后继续补充，也能按关键词或日期查找。我还想回看这些记录之间的关联：我读一本书时为什么会被触动，可能和以前经历的一件事有关。我给自己设置了每周回看的任务，看看时间花在什么事情和信息上。与此同时，我也希望主动接触一点平时不会被推荐给我的信息。回看帮助我了解自己，接触不同的信息帮助我看到更大的世界。

演示时，我用中文记录了一段正在和大家分享工具的笔记，再打开仓库看它存在哪里。有人问能不能在手机上用，有人问数据放在哪里。这些问题也提醒我，前面的连接和设置仍然有步骤，不是对每个人都没有门槛。我之前做过工作坊，这次是把一些重复步骤封装起来，想提供一个更容易使用的入口。不是大家一定要用 AI，也不是一定要用 GitHub 记录。

李影问了另一个问题：会不会记录疲劳？工具已经把阻力降得很低，可有时连语音都不想说，只想待在那个时刻里。我确实也有这样的状态。真的疲劳时，一天没有记，就没有记，没关系。隔一天、两天，想起来以后，我可能再用几分钟补录。

我也想过，记录会不会让我没有那么沉浸地生活。有一次，我一个人爬山，一直和 AI 聊想法，确实忽略了身边的风景和气味。什么算在场？沉浸在思考里，或者沉浸在环境里，对我来说都可能成立，但前提还是服务于自己，也尽量有意识地感受、观察、认真生活。

我不觉得一定得天天记录，也不觉得只有很深、很有价值的感受才值得留下。没什么特别的感受，想记，也可以记。以后即使不用这个工具了，我还是希望这些记录能被保留下来，能够转移、收藏，继续属于我自己的生活。
